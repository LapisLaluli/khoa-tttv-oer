Hệ Thống Quản Trị Website Tài Nguyên Giáo Dục Mở

Hệ thống cho phép bạn toàn quyền thêm mới, chỉnh sửa, xóa và kiểm soát mọi nội dung và hình ảnh trên website:

  • Hình ảnh & Giao diện: Tải lên ảnh Logo, ảnh nền Banner chính, bộ ảnh khối Về Chúng Tôi trực tiếp từ máy tính.
  • Quản lý Mốc lịch sử: Cập nhật mốc son phát triển, ảnh tư liệu scan, nguồn kiểm chứng OER.
  • Hoạt động nổi bật: Quản lý bài viết về hội thảo khoa học, triển lãm sách, kiến tập và phong trào sinh viên.
  • Tài nguyên giáo dục mở: Quản lý bài đọc ngắn, kỷ yếu số hóa và bản quyền Creative Commons.
  • Sao lưu dữ liệu: Xuất toàn bộ dữ liệu ra file JSON chỉ với một thao tác.

Tùy Biến Hình Ảnh Giao Diện & Thương Hiệu

Tải ảnh trực tiếp từ máy tính của bạn hoặc nhập đường dẫn file. Ảnh sẽ hiển thị ngay lập tức trên website.

1. Logo Khoa & Trường

Hiển thị trên thanh menu chính và chân trang footer.

2. Ảnh Nền Banner Hero Chính

Ảnh nền khu vực tiêu đề đầu trang chủ.

3. Ảnh Khối Về Chúng Tôi (Khung lớn)

Vị trí ảnh sinh viên học tập & nghiên cứu.

4. Ảnh Khối Về Chúng Tôi (Phía trên)

Không gian kết nối tri thức / Thư viện.

5. Ảnh Khối Về Chúng Tôi (Phía dưới)

Tư liệu sách và văn hóa (People Books).

6. Ảnh Nền Khối Trích Dẫn

Ảnh nền dải băng trích dẫn danh ngôn giữa trang.

Trung Tâm Sao Lưu & Xuất Dữ Liệu

Mọi thay đổi của bạn trên trang Admin được lưu tự động trong máy. Bạn có thể xuất file sao lưu hoặc khôi phục dữ liệu:

1. Xuất file dữ liệu JSON

Tải về file JSON chứa toàn bộ hình ảnh, mốc lịch sử, hoạt động và cấu hình.

2. Nhập file dữ liệu JSON

Nạp lại dữ liệu từ file backup đã xuất trước đó.

3. Quản lý & Xóa tệp đã tải

Xóa sạch các tệp ảnh tùy chỉnh và giải phóng bộ nhớ trình duyệt.
