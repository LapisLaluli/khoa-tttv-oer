# Dấu ấn Thông tin – Thư viện

Website mẫu OER mô phỏng bố cục và cảm giác thị giác của ảnh tham chiếu: header sáng, hero ảnh lớn, các khối giá trị, phần giới thiệu, timeline, tài nguyên, thống kê và footer.

## Công nghệ
- HTML5
- CSS3
- JavaScript thuần
- JSON
- GitHub Pages

## Cách chạy
Mở `index.html` bằng trình duyệt. Vì timeline và quiz đọc JSON bằng `fetch`, nên tốt nhất chạy bằng một web server cục bộ, ví dụ VS Code + Live Server.

## Những phần phải thay trước khi nộp
1. Thay `assets/images/logo-placeholder.svg` bằng logo được phép sử dụng.
2. Thay `assets/images/placeholder.svg` bằng ảnh tư liệu có quyền sử dụng.
3. Thay toàn bộ dữ liệu mẫu trong `data/milestones.json`.
4. Thêm nguồn, link và thông tin giấy phép cho từng tư liệu.
5. Bổ sung file PDF/infographic thật trong thư mục `documents/`.
6. Kiểm tra toàn bộ dữ kiện lịch sử trước khi xuất bản.
7. Cập nhật thông tin liên hệ và tên nhóm.
